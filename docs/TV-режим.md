# TV-режим

Крупный интерфейс панели для просмотра с дивана: телевизор, пульт, Kodi,
старые CRT (NTSC/PAL) и современные LCD.

## Зачем

Обычные страницы панели рассчитаны на мышь и близкое расстояние. TV-режим
(`/tv`) показывает только самое нужное крупными блоками:

- время и дата;
- температура, CPU, RAM, аптайм;
- устройства в сети (онлайн/всего), доступность интернета;
- погода;
- последние события.

## Как открыть

- Прямая ссылка: `http://<ip-панели>:8080/tv` (нужен вход в панель).
- Иконка «TV-режим» (📺) на рабочем столе Applications.

## Управление пультом / клавиатурой

| Клавиша | Действие |
|---|---|
| ← ↑ → ↓ | Перемещение по блокам |
| Enter / OK | Активировать кнопку |
| Backspace / Esc / ← (Backspace пульта) | Назад в панель (`/`) |
| `+` / `-` | Масштаб крупнее / мельче |
| `0` | Масштаб по умолчанию |

Масштаб и поля (safe-зона) запоминаются в браузере и применяются при
следующем открытии. Подходят под overscan старых CRT-ТВ (по умолчанию
поля 5%).

## Kodi

В Kodi нет встроенного браузера. Варианты открыть `/tv`:

- **CoreELEC / LibreELEC (Android/AML-боксы)**: установите addon
  «WebBrowser» (Chromium) или «Chrome Launcher» из репозитория addon-ов;
  Kodi запустит браузер в полноэкранном окне — панель выглядит как ещё
  одно приложение Kodi.
- **Android TV / Google TV**: Kodi → Аддоны → «Android apps» (или
  лаунчер) → браузер (Chrome/Firefox) → адрес панели; либо готовый
  addon `tools/kodi/plugin.video.landiscovery` из этого репозитория —
  он открывает браузер с URL панели одной кнопкой.
- **PC/LibreELEC с мышью**: обычный браузер, F11 на весь экран.

### Плагин `plugin.video.landiscovery`

Лежит в `tools/kodi/plugin.video.landiscovery/`. Установка:

1. Скопируйте папку аддона на устройство (или запакуйте в .zip и
   «Установить из zip-файла» в Kodi).
2. Откройте аддон → «Настройки» → укажите URL панели
   (например `http://192.168.3.243:8080`).
3. «Открыть панель» запускает системный браузер с этим URL
   (Android: intent, Linux: chromium/google-chrome).

## CRT: рекомендации

- Включите TV-режим и подберите масштаб кнопками `+`/`-`, пока текст
  не станет читаемым с вашего расстояния.
- Если края обрезаются (overscan) — увеличьте safe-поле (− масштаб
  не поможет, поля регулируются на странице блоками «Поля»).
- На PAL (576i) и NTSC (480i) хорошо работает масштаб 150–200%.
