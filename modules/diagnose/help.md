# Диагностика сети («Что сломано?»)

Один прогон проверяет цепочку от компьютера до интернета и отвечает
на вопрос «что сломано?».

## Шаги проверки

| Шаг | Что делает | Типичная причина fail |
|-----|-----------|----------------------|
| Локальная сеть | IPv4-адрес, шлюз, DNS-серверы, источник адреса (DHCP/статик) | нет адреса, не задан шлюз |
| Шлюз роутера | ping шлюза ×3 | роутер выключен/завис |
| DNS | резолв ya.ru, google.com, cloudflare.com | кривые DNS в настройках |
| Интернет | HTTP-пробы: gstatic generate_204, google generate_204, ya.ru | нет WAN у провайдера |
| Потери и задержки | ping 8.8.8.8 ×5: loss %, min/avg/max | нестабильная линия |
| Скорость | download-тест с зеркал (tele2 → cachefly → thinkbroadband) | медленный канал |

## Как читать результат

- **Всё в порядке** (зелёный) — цепочка «комп → роутер → DNS → интернет» работает.
- **Есть замечания** (жёлтый) — частичные потери, часть имён не резолвится,
  зеркала скорости недоступны. Часто бывает нормой.
- **Проблемы** (красный) — список шагов, которые упали. Лечить сверху вниз:
  сначала LAN/шлюз (роутер, кабель, Wi-Fi), потом DNS, потом интернет у провайдера.

## Замечания

- Ping WAN (8.8.8.8) может не проходить из-за ICMP-фильтров провайдера —
  при зелёных HTTP-пробах это не проблема.
- Тест скорости качает до ~12 с с первого доступного зеркала; при отсутствии
  интернета шаг пропускается.
- Шаг можно отключить (чекбокс «Без теста скорости») — прогон быстрее.
- Диагностика идёт от имени самой панели — проблемы клиента,
  с которого вы открыли страницу, не видны.
