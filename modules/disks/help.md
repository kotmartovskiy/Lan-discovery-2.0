**Где это:** плитка «Диски» на /apps (оверлей).

### Просмотр
- Инфо о дисках: `lsblk`, `df`, S.M.A.R.T.-атрибуты (если установлен `smartmontools`).
- API: `GET /api/disks`.

### Disk Manager (расширение 23.10.2026, модуль `disks` v2.1)
Полноценная работа с накопителями прямо из плитки «Диски»:

- **Разделы:** таблица (parted), создание/удаление разделов.
- **Форматирование:** ext4/ext3/ext2, vfat, ntfs, exfat, btrfs, xfs — с меткой.
- **SMART:** здоровье, температура, таблица атрибутов.
- **Проверка ФС:** `e2fsck -n` (read-only) для ext-разделов.
- **Клонирование:** целый диск → целый диск (dd с прогрессом, остановка).
- **Загрузочные образы:** FreeDOS 1.3 (скачивание с официального зеркала
  ICM.edu.pl, кэш в `/var/cache/lan-discovery/disktool`) + свои `.img/.iso`
  (загрузка до 700 МБ) → запись на диск (dd). Удобно для USB-дисководов:
  FreeDOS-образы дискет 1.44М/1.2М и флешка LiteUSB.

### Безопасность (fail-closed)
- Деструктивные операции — только на **целых дисках** без смонтированных
  разделов и **не на системном диске** (тот, что смонтирован на `/`).
- Запрет на zram/loop/fd/sr и `*boot*`-устройства (eMMC-boot и т.п.).
- Имя устройства валидируется (`[a-zA-Z0-9]+`, без путей).
- Все мутации — только admin + CSRF; долгие операции идут в фоне
  (`/api/disktool/status` — поллинг прогресса).

- Выключенный модуль: плитка скрыта, `/apps/disks` и `/api/*` → 404.
