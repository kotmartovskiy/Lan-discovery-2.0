# Hardware-инструменты (Flipper-направление)

Единая страница `/flipper` для работы с внешним железом: SDR-приёмник,
USB-UART, программаторы. Панель сама определяет, что подключено и что
установлено; недостающее ставится кнопками на странице (нужен admin).

## SDR-пейджер (rtl_433)

Live-лента сообщений с 433/868/915 МГц приёмников: погодные станции,
датчики давления, шинные датчики TPMS, пульты, умные розетки.

- Железо: RTL-SDR dongle (R820T/R828D и т.п.) в USB.
- Софт: `rtl-sdr` + `rtl-433` (кнопки установки на странице).
- Запуск: rtl_tcp не нужен — страница сама держит `rtl_433 -F json`.
- Нет dongle → состояние «приёмник не найден», а не ошибка.

## Serial-консоль

Список UART-портов (`/dev/ttyUSB*`, `/dev/ttyACM*`, `/dev/ttyS*`) и
простой монитор: открыть порт с нужной скоростью, читать лог, писать
строку. Консольные порты ядра (`/proc/consoles`, например ttyS2)
помечаются и **не открываются** — можно убить доступ к панели.

- Железо: USB-UART адаптер (CH340/CP2102/FT232/PL2303).
- Софт: `pyserial` (кнопка установки).

## Программаторы

Прошивка микроконтроллеров с панели (файл загружается, параметры —
только из выпадающих списков):

| Инструмент | Кто | Софт |
|-----------|-----|------|
| avrdude | ATmega/ATtiny (arduino, usbasp…) | `avrdude` |
| esptool | ESP8266 / ESP32 | `esptool` |
| stm32flash | STM32 (UART bootloader) | `stm32flash` |

Порт программатора — только USB/ACM (ttyACM/ttyUSB); встроенные ttyS*
не предлагаются.

## NFC / IR

Страница показывает, обнаружено ли железо (PN533-модули, LIRC/gpio-ir).
Если нет — раздел справочный: поддержка появится, когда модуль будет
подключён. Пока можно использовать панель как точку входа — железо
подключается к USB/UART бокса и определится автоматически после
переподключения.

## Безопасность

- Установка пакетов — только admin и только из whitelist.
- Команды программаторов собираются из whitelist-полей на сервере;
  произвольные аргументы не передаются.
- Загруженные прошивки лежат в `/tmp/flipper/` (не на eMMC).
