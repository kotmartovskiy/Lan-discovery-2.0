# Дом и сигнализация

Домашняя сигнализация на GPIO-боксе с MQTT-мостом.

## Возможности

- **Зоны** — GPIO-входы с контактыми (reed) датчиками门窗/дверь/ворота.
  Уровень срабатывания настраивается (0/1). Зона «открыта» = вход равен
  trigger_level.
- **Сирена** — GPIO-выход: включается при тревоге, выключается при снятии
  охраны. Настраивается как зона `__siren__`.
- **Охрана** — кнопки «Поставить/Снять». Пока охрана включена, панель
  опрашивает зоны каждые 2 с; открытие зоны → тревога + сирена +
  событие `home.alarm_triggered` (critical) + MQTT.
- **MQTT** — публикация состояния (retained, topic `<prefix>/state`) и
  событий (`<prefix>/event`) на брокер. Клиент `mosquitto-clients`
  ставится кнопкой (admin).
- **Датчики** — CPU-температура и текущие уровни GPIO-входов на странице.

## Подключение датчика (reed) к GPIO

1. Контакт датчика — к GPIO-пину (напр. gpiochip0 line 18 = PA18).
2. Второй контакт — к GND.
3. В панели: «Добавить зону» → chip `gpiochip0`, line `18`,
   trigger_level `0` (внутренний pull-up: закрыт = 1, открыт = 0).
4. Проверить значение кнопкой «Тест».

## Сирена

Зона с именем `__siren__` (chip/line) — выход: при тревоге `gpioset 1`,
при снятии охраны `0`. Проверка — кнопка «Сирена вкл/выкл».

## MQTT

Топик `<prefix>/state` (retained):
```json
{"armed": true, "triggered": false, "triggered_zone": null,
 "siren": false, "zones": [{"name": "дверь", "open": false}],
 "ts": "21.10.2026 12:00:00"}
```
Топик `<prefix>/event` — события (arm/disarm/тревога).

## Ограничения

- GPIO доступен только на боксах с gpiochip (см. линейки GPIO в
  документации платы); на боксах без gpiochip —
  страница показывает «GPIO не найден», зоны не добавляются.
- Тревога снимается только вручную (disarm) — автоматика не отключает
  её при закрытии датчика (защита от «мимолётных» открытий).
- MQTT best-effort: недоступный брокер не роняет сигнализацию.
