# Сканер открытых портов

Сканирует выбранный диапазон IP на открытые TCP-порты и сохраняет
результат в текстовый файл на **HDD/SSD** (запись на eMMC/SD отключена —
без подключённого диска сканирование не запускается).

## Как пользоваться

1. **Диапазон IP** — CIDR (`192.168.3.0/24`), список через запятую,
   диапазон (`192.168.3.1-192.168.3.50` или `192.168.3.1-50`).
   Максимум 4096 хостов.
2. **Порты** — `top` (частые), `all` (1–65535), диапазон (`1-1024`),
   список (`22,80,443,8000-8100`).
3. **Таймаут** — время на попытку соединения (0.3–2.0 с).
4. Нажать **Запустить**. При объёме более 500 000 комбинаций
   (хосты × порты) требуется галочка «Подтверждаю».

Прогресс и открытые порты видны в блоке «Статус», файл появляется
в «Файлы результатов» по мере нахождения открытых портов.

## Файл результата

Текстовый файл `portscan-YYYYMMDD-HHMMSS.txt` (шапка с параметрами,
строки вида `ip:port/tcp open service (N ms)`, сводка в конце).

Каталог по умолчанию:

- `/srv/lan-discovery/portscan` — если `/srv/lan-discovery` на HDD;
- иначе — задайте `portscan.results_dir` в
  `/etc/lan-discovery/settings.json` на путь на подключённом HDD/SSD.

## Доступ

Просмотр и запуск — только авторизованные пользователи; запуск/остановка/
удаление файлов — только с правом «Редактирование» (admin).
