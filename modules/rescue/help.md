# Спасательный AP (rescue)

Wi-Fi точка доступа на боксе для доступа к панели, когда падает
основная сеть (роутер/провайдер). Подключаетесь к SSID **LAN-Rescue**
и заходите на `http://192.168.4.1:8080`.

## Как пользоваться

1. (один раз) Кнопки **Установить hostapd** и **Установить dnsmasq** —
   admin, ставятся из apt.
2. Выберите свободный `wlan`-интерфейс (не тот, что с default route —
   он помечен «аплинк», на нём AP не поднимется, чтобы не оборвать сеть).
3. Задайте SSID/пароль (или оставьте открытую сеть для быстрого спасения),
   канал, подсеть — **Сохранить**.
4. **Запустить AP** — бокс вещает точку доступа; DHCP выдаёт адреса
   в подсети (по умолчанию 192.168.4.10–100).
5. **Остановить** — интерфейс возвращается в исходное состояние.

## Ограничения

- AP живёт, пока включён бокс — это спасательный, а не постоянный режим.
- WPA2-PSK (открытая сеть — только если пароль пуст).
- Если wlan0 — сам аплинк (единственный сетевой выход), AP поднять
  нельзя без потери связи: нужен второй Wi-Fi донгл или Ethernet.
- Системные юниты не трогаются; конфиги в `/etc/lan-discovery/rescue/`.
