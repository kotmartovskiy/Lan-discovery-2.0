# SDR-радио (виджет rtl_tcp)

Лёгкий виджет для RTL-SDR свистка поверх сервиса `rtl_tcp` (порт 1234):

- **водопад и спектр** в реальном времени (WebSocket/SocketIO, без lighttpd);
- **настройка частоты** (ввод, шаг ±, пресеты) — команда SET_FREQ уходит в rtl_tcp на лету;
- **прослушивание FM/AM** прямо в браузере (простой клиентский демод, УКВ/средние волны).

## Требования
- USB-свисток RTL2832U (RTL-SDR);
- запущен `rtl_tcp` (кнопка «Запустить rtl_tcp» на странице, либо `systemctl start rtl_tcp`);
- модули ядра dvb-rtl-sdr уже установлены.

## Полноценный приёмник
Для качественного приёма (SSB/CW/цифровые режимы, несколько слотов, запись) используй плитку **OpenWebRX** — там веб-интерфейс с водопадом, demod и профилями.

## Ограничения
- виджет слушает один сигнал за раз (один rtl_tcp-клиент на боксе);
- без свистка страница показывает заглушку;
- демо-режим без железа: спектр пустой, пока не вставлен свисток.
