# Внешний вид

Настройка темы, фона и акцента панели.

## Тема
- **Авто** — следует за системной темой ОС (`prefers-color-scheme`);
- **Тёмная** — классический тёмный интерфейс (по умолчанию);
- **Светлая** — светлые поверхности и контрастный текст.

## Фон
Подложка под содержимым панели: нейтральный (сплошной) или с мягким
градиентным свечением по краям — «Аврора», «Закат», «Лес».

## Акцент
Цвет кнопок, ссылок и активных элементов интерфейса: синий, фиолетовый,
зелёный, оранжевый, розовый, бирюзовый.

## Хранение
- Выбор сохраняется в браузере (localStorage, ключ `ld_ui`) и применяется
  мгновенно, без перезагрузки страницы.
- У администратора есть кнопка «По умолчанию для всех» — она записывает
  выбранный вид в секцию `ui` настроек панели
  (`/etc/lan-discovery/settings.json`), и он станет стартовым для всех
  пользователей. Приоритет: браузер → глобальный дефолт → `dark/mono/blue`.

Заметки: фоновые градиенты и акценты применяются через атрибуты
`data-theme` / `data-bg` / `data-accent` на `<html>`; реализация —
`static/style.css`, секции 8–9. Тема `auto` переключается при изменении
системных настроек, не перезагружая страницу.
