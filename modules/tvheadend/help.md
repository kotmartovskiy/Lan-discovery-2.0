**Где это:** плитка «TVheadend» на странице «Приложения» (категория «Медиа»).

- Веб-интерфейс tvheadend встроен iframe'ом напрямую с порта `9981`
  (авторизация своя, при первом входе — создание учётки администратора).
- Дальше мастер настройки: поиск DVB-адаптеров → скан частот (`w-scan`)
  → мультиплексоры → источники EPG → запуск HTSP (для Kodi).
- PVR в Kodi: пакет `kodi-pvr-hts` установлен; указать адрес
  `192.168.3.243`, порт `9981`.

**Сервис и конфиг:**

- `systemctl status tvheadend` — состояние; конфиг: `/usr/local/share/tvheadend`.
- Собран из исходников (`/usr/src/tvheadend`), пересборка — `make && make install`.

**Зависимости модуля:** сервис `tvheadend` — ставится кнопкой
«Установить зависимости» на странице «Модули» (админ).

**Если модуль выключен:** плитка скрыта. Включить обратно можно на
странице «Модули» (админ).
