**Где это:** вкладка «Погода» + краткий статус в шапке панели.

- Локация: Иваново (57.0°N, 41.0°E), часовой пояс Europe/Moscow, источник — Open-Meteo API.
- Карточки: температура, «ощущается как», ветер, влажность, давление, UV-индекс, видимость, восход/закат.
- Прогноз: почасовой + на 5 дней, история за 24 часа, радиационный фон (мкЗв/ч), качество воздуха AQI.
- Выходные дни в таблице прогноза подсвечены красным.
- Обновление данных каждые 30 минут; кэш API-ответов — 15 минут.
- UV-индекс: шкала 0–11+ с цветовыми зонами и рекомендациями по защите от ультрафиолета.
- Радиационный фон: единицы мкЗв/ч, статусы Норма / Повышенный / Высокий / Опасный
  (пороги ≤0.2 / ≤0.5 / ≤1.0 мкЗв/ч), норма ≤0.2 мкЗв/ч;
  источник — ЕГАСМРО (egasmro.ru, ближайшие пункты к выбранному населённому пункту:
  название, расстояние, направление, дата замера).
- Качество воздуха AQI: шкала 0–500, параметры PM2.5, PM10, CO, NO₂ с рекомендациями по здоровью.
- «Пульс сервера»: latency (задержка ответа), CPU, RAM, disk, uptime.
- Статус обновления в шапке: `GET /api/weather-status` (элемент `#weather-status`).
- Кэширование ответов ~15–30 минут; при недоступности API показываются последние данные.
- Зависимости модуля: нет (Open-Meteo API, пакеты не нужны).
- Выключенный модуль: вкладка скрыта, `/weather` и `/api/weather*` → 404.
