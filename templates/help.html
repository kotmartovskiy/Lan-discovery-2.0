👋 Обзор панели

LAN Discovery — самодельная домашняя панель-«прошивка» для одноплатника ({{ hf.board }}): сеть, устройства, мониторинг, хранилище, приложения, автоматизация и системные инструменты в одном веб-интерфейсе.

Как войти

  • Откройте {{ hf.panel_url }} (порт {{ hf.web_port }}) с любого устройства в LAN.
  • Пароль задан при установке; без логина часть страниц закрыта (перенаправление на вход).
  • Аварийный доступ: {{ hf.restore_url }} — минималистичный сервер, работает когда панель легла.

Как устроена навигация

  • Сверху — 8 вкладок (Home, Network, Monitoring, Storage, Applications, Hardware, System, Admin): они группируют страницы по смыслу.
  • Внутри вкладки — пункты меню (например, Network → Устройства, Инвентаризация, Диагностика).
  • Вкладка Applications — плитки встроенных приложений и игр.
  • Внизу — строка состояния: CPU, RAM, eMMC, HDD, LAN/Wi-Fi трафик (сразу видно, всё ли в порядке).
  • Шапка: часы, погода, «Интернет: доступен/нет», здоровье системы; справа в шапке — бейджи задач (jobs), если что-то выполняется.
С чего начать: откройте Home — это сводка; потом Network → Устройства для обзора LAN; всё остальное — по необходимости. Эту справку можно читать сверху вниз или переходить по оглавлению слева; наверху есть «Раскрыть всё / Свернуть всё».

🏠 Вкладка HOME

Рабочий стол панели: одна страница, с которой видно общее состояние дома/сервера.

Главная (/)

Что это: сводный дашборд — здоровье системы (CPU, RAM, диск, температура), счётчики устройств онлайн/офлайн, последние события, погода и курсы валют.

Как пользоваться: смотрите карточки сверху; клик по блоку здоровья открывает детали; события прокручиваются ниже — там видно, что устройство выходило в сеть или появлялось. Обновляется автоматически.
🌐 Вкладка NETWORK — сеть и устройства

Устройства (/devices)

Что это: главный список устройств LAN: сканирование (ARP/nmap), IP, MAC, имя, статус онлайн/офлайн, веб-порты устройств.

  • Зелёный — онлайн, серый — офлайн, жёлтый — новое устройство (ещё не встречалось).
  • Клик по строке — карточка устройства: история, открытые порты, веб-интерфейс.
  • Имя устройству задаётся вручную (потом не сбрасывается при сканах).
  • Ручной запуск скана кнопкой; фоновый скан по расписанию настраивается в System → Настройки.
Как пользоваться: откройте вкладку → дождитесь скана (или нажмите «Сканировать») → кликните устройство, чтобы посмотреть детали.

Инвентаризация (/inventory)

Что это: учётная таблица техники: что за устройство, серийники, комментарии, привязка к месту — чтобы не терять, где что лежит.

Как пользоваться: добавьте запись → заполните поля → при сканировании сети устройство сопоставляется по MAC/IP с записью инвентаря.

Диагностика сети (/diagnose)

Что это: набор проверок связности: ping, доступность портов, DNS, HTTP-ответы — одним нажатием видно, что сломалось.

Как пользоваться: выберите проверку → запустите → смотрите вердикт (зелёный/красный) и подробности; при отказе HTTP есть fallback на TCP.
📊 Вкладка MONITORING — история и метрики

История (/history)

Что это: лента событий панели: устройства появлялись/исчезали, смены MAC, результаты сканов, системные уведомления. Фильтры по типу и времени.

Как пользоваться: выберите период/фильтр → смотрите ленту; клик по событию открывает контекст (устройство, результат).

Мониторинг (/monitoring)

Что это: метрики этой панели во времени: CPU, RAM, диск, температура, сеть — в виде карточек и графиков.

Как пользоваться: откройте страницу — графики рисуются сами; за пределами встроенного мониторинга — вкладка приложения Netdata (полный мониторинг).

Валюты (/currencies)

Что это: курсы в одном месте: криптовалюты (CoinGecko), fiat-валюты (Frankfurter), металлы (Yahoo Finance), цены приёмных пунктов (ЦФО).

Как пользоваться: просто откройте вкладку — данные подтягиваются автоматически; карточки обновляются фоном (кэш).

Погода (/weather)

Что это: текущая погода и прогноз (Open-Meteo) по координатам {{ hf.coords }}; виджет погоды также стоит в шапке.

Как пользоваться: координаты/регион меняются в System → Настройки (блок «Местоположение»); дальше всё обновляется само.
💾 Вкладка STORAGE — диски

Хранилище (/storage)

Что это: все накопители системы: корень ({{ hf.root_kind_label }}), SD, eMMC, HDD — разделы, точки монтирования, занятое/свободное место.

  • Видно, где система, а где данные (загрузки, бэкапы).
  • Подсказки по заполненности — чтобы вовремя чистить или переносить на HDD.
Как пользоваться: откройте вкладку и смотрите таблицы; подробнее о дисках — приложение «Диски» и вкладка System (клонирование, бэкапы).
🧩 Вкладка APPLICATIONS — приложения и игры

Что это: «рабочий стол» со встроенными приложениями: утилиты, медиа, игры, сетевые инструменты. Всего {{ 9 + 19 }} плиток, каждая открывает встроенный виджет или отдельную страницу модуля.

  • Иконки-плитки сгруппированы по категориям: Утилиты, Медиа, Игры, Система и сеть.
  • Наведение — плитка приподнимается; клик — открывает приложение.
  • Полное описание каждого приложения — в разделе «Все приложения» ниже в этой справке.

Торрент (/torrent)

Что это: веб-интерфейс торрент-клиента Transmission: добавление магнит-ссылок, список раздач, скорость, статус.

Как пользоваться: вставьте магнит → файлы попадут в /srv/downloads/; управляйте раздачами прямо из списка.
🔧 Вкладка HARDWARE — железо и дом

Возможности (/capabilities)

Что это: паспорт аппаратуры этой панели: архитектура, доступные шины и инструменты (GPIO, serial, i2c…), накопители, что модулям разрешено использовать.

Как пользоваться: смотрите, что есть на плате, прежде чем включать модули, требующие железо (SDR, DVB, GPIO); здесь же видно, чего нет.

Hardware-инструменты (/flipper)

Что это: низкоуровневые инструменты для отладки железа: тесты GPIO-ножек, шины i2c/spi/serial, шлюз к Flipper Zero-подобным проверкам.

Как пользоваться: выберите интерфейс/ножку → запустите тест → смотрите результат; удобно перед подключением датчиков.

Дом и сигнализация (/home)

Что это: домашняя сигнализация: GPIO-зоны (контактные датчики reed), сирена, режим «под охраной», MQTT-мост (состояние/события в умный дом), датчик температуры CPU.

  • Зоны привязываются к GPIO-ножкам платы (chip/line), опрос раз в 2 секунды.
  • Открытие зоны под охраной → тревога: сирена + событие home.alarm_triggered + MQTT retained-состояние.
  • MQTT: клиент ставится кнопкой (admin), работает с внешним брокером.
Как пользоваться: добавьте зону (chip/line) → включите сирену при необходимости → «Поставить под охрану» → при открытии датчика сработает тревога; «Снять» — отключает. События видны в Истории.
⚙️ Вкладка SYSTEM — сервер целиком

Система (/system)

Что это: «пульт» сервера — главная административная страница. Карточки состояния и блоки управления:

  • Состояние: uptime, нагрузка, температура, RAM, SD, eMMC.
  • Сервисы: старт/стоп/рестарт (Transmission, MiniDLNA, Samba, панель, Netdata…).
  • Гостевой доступ Samba: доступ к шарам без пароля в LAN (только admin).
  • Бэкапы: файлы панели и базы данных (создание/восстановление).
  • Клонирование SD ↔ eMMC: перенос системы между картами (с проверками).
  • IPTV: добавление/обновление плейлистов m3u.
  • Сеть: подсеть, интерфейсы скана, фоновый скан, тестовые адреса.
  • Местоположение и погода: координаты, часовой пояс, регион.
  • Настройки вида и Внешний вид: тема/фон/акцент панели.
  • Питание: перезагрузка и выключение (с подтверждением).
Как пользоваться: каждая карточка самодостаточна — меняете значение и жмёте «Сохранить/Применить»; опасные действия просят подтверждение.

О системе (/about)

Что это: полный паспорт: плата, процессор, память, накопители, сеть, USB, файловые системы, установленное ПО и версии сервисов.

Как пользоваться: страница для справки и отчётов — ничего не меняет, только показывает.

Справка (/help)

Что это: эта страница — раскрывающееся руководство по всему.

🛡 Вкладка ADMIN — управление (только admin)

Вкладка видна только администратору; без роли admin пункты скрыты.

Роли (/roles)

Что это: профили доступа — default, media, network: пакетное включение/выключение модулей «под роль» (например, «домашний медиа-центр» — только медиа-приложения). Есть compat-check: несовместимые модули пропускаются.

Как пользоваться: выберите профиль → «Применить» → панель переключит набор модулей; изменения вступают в силу сразу.

Модули (/modules)

Что это: менеджер модульной системы: включение/выключение разделов, установка зависимостей (apt/pip/сервисы), версии, а также каталог модулей с GitHub (установка/обновление/удаление внешних модулей).

Как пользоваться: включите нужный модуль → если требуется, нажмите «Установить зависимости»; выключенный модуль исчезает из навигации и гасит свои URL.

Automation (/automation)

Что это: правила «событие → действие»: например, «устройство вышло в сеть → записать в лог/отправить событие». Реестр действий расширяется модулями.

Как пользоваться: «Добавить правило» → выберите триггер (событие) и действие → сохраните; правилом можно включать/выключать (toggle) и удалять. Логи событий — во вкладке Monitoring → История.
📱 Все приложения: описание и как пользоваться

Плитки вкладки Applications открываются кликом. Ниже — каждое приложение: что это и как пользоваться. Модульные приложения (Сеть, Wi-Fi, Bluetooth…) работают только когда их модуль включён (Admin → Модули).

Утилиты
🔢 Калькулятор

Описание: обычный и инженерный режимы: тригонометрия, логарифмы, степени, скобки.

Как пользоваться: набирайте выражение кнопками → результат в дисплее; кнопка режима переключает между простым и инженерным.

📅 Календарь

Описание: месячная сетка с ежедневными задачами; задачи хранятся в браузере (localStorage) — не пропадают после перезагрузки страницы.

Как пользоваться: выберите день → «Добавить задачу» → текст; редактирование и удаление — кликом по задаче.

⏳ Таймер

Описание: обратный отсчёт с настраиваемым временем и звуковым сигналом по окончании.

Как пользоваться: задайте часы/минуты/секунды → «Старт»; по нулю — звук. «Сброс» возвращает время.

⏱ Секундомер

Описание: точный отсчёт и фиксация промежуточных кругов (laps).

Как пользоваться: «Старт» → «Круг» фиксирует время круга (список ниже) → «Стоп»; «Сброс» обнуляет всё.

⏰ Будильник

Описание: пробуждение по времени: однократно, ежедневно или по дням недели, со звуковой мелодией.

Как пользоваться: задайте время → выберите повтор → «Включить». Будильник сработает, пока вкладка открыта.

📝 Заметки

Описание: быстрые текстовые заметки с хранением в базе панели — доступны с любого устройства после входа.

Как пользоваться: «Новая» → заголовок и текст → сохранить; редактирование и удаление — из списка.

🔐 Пароли

Описание: генератор стойких паролей с настройкой длины и наборов символов.

Как пользоваться: выставьте длину и типы символов → «Сгенерировать» → «Копировать». Хранение паролей — в зашифрованном виде (вкладка Paroli/секреты).

📁 Файлы

Описание: файловый менеджер панели: просмотр каталогов, чтение файлов, создание/переименование/копирование/удаление (права admin).

Как пользоваться: переходите по каталогам как в проводнике; действия — кнопками строки; аккуратно с системными путями.

Медиа
📻 Радио

Описание: плеер онлайн-радио: свои станции (URL потока + название) и предустановки.

Как пользоваться: выберите станцию из списка → «Play»; новую добавьте кнопкой «Добавить» (вставьте URL http(s)://…/stream).

🎵 Плеер

Описание: воспроизведение локальных медиафайлов с накопителей панели (аудио/видео), список файлов, перемотка, громкость.

Как пользоваться: откройте папку с файлами → клик по файлу — воспроизведение; управление — панелью плеера.

📷 Камеры

Описание: подключение IP-веб-камер по потокам RTSP/HTTP: просмотр в панели одним местом.

Как пользоваться: «Добавить» → введите URL потока (rtsp://… или http://…/video) → имя → сохранить; поток появится в списке.

📺 TVheadend

Описание: тюнер DVB-T2: просмотр каналов и запись ТВ прямо в панели (встроенный iframe TVheadend).

Как пользоваться: откройте приложение → выберите канал; настройки тюнера — внутри TVheadend.

📻 SDR-радио

Описание: приёмник RTL-SDR: настройка частоты, демодуляция, просмотр спектра — радиолюбительские эфиры и локальные передатчики.

Как пользоваться: подключите RTL-SDR (USB) → задайте частоту и режим → «Старт»; управление частотой доступно и кнопками.

Игры
🐍 Змейка

Описание: классическая «змейка»: собирайте еду, не врезайтесь в стену/хвост.

Как пользоваться: управление — WASD или стрелки; кнопки старта/паузы в окне игры.

🟦 Тетрис

Описание: падающие фигуры, уровни сложности, удержание (hold) фигуры, нарастающая скорость.

Как пользоваться: стрелки — движение/поворот; Space — сброс; удержание фигуры — клавишей hold.

🟩 2048

Описание: складывайте одинаковые числа на поле 4×4, цель — плитка 2048.

Как пользоваться: стрелки сдвигают всё поле; слияние одинаковых чисел даёт их сумму.

🟪 Арканоид

Описание: разрушение кирпичей мячом с ракеткой, несколько уровней.

Как пользоваться: мышь или стрелки двигают ракетку; мяч отскакивает, пока не упадёт.

Система и сеть
📈 Netdata

Описание: полный мониторинг системы в реальном времени (CPU, RAM, диск, сеть, процессы) — встроенный Netdata, порт 19999.

Как пользоваться: просто откройте приложение — дашборды рисуются сами; сервис должен быть запущен (System → Сервисы).

💻 Терминал

Описание: веб-терминал: shell этой панели прямо в браузере (аналог SSH).

Как пользоваться: откройте → подключитесь → работайте с командами как в консоли. Осторожно: это root-доступ.

🔌 Сеть

Описание: сетевые утилиты: ping, traceroute, DNS-резолвинг, whois, проверка портов — все проверки в одном окне.

Как пользоваться: выберите утилиту → введите адрес → «Запустить» → смотрите вывод и время ответа.

🛰 Сканер портов

Описание: сканирование открытых портов цели (nmap): какие сервисы запущены на устройстве.

Как пользоваться: введите IP → диапазон портов (или весь) → «Сканировать» → результат таблицей.

📡 Wi-Fi

Описание: анализатор Wi-Fi-эфира: доступные сети, каналы, уровень сигнала (RSSI) — чтобы выбрать свободный канал роутера.

Как пользоваться: запустите анализ → смотрите список сетей и занятость каналов (чем меньше сетей на канале — тем лучше).

💾 Диски

Описание: детальная информация о дисках и разделах: размеры, ФС, свободное место, точки монтирования.

Как пользоваться: откройте приложение — данные по всем дискам сразу; для действий с дисками — вкладка Storage/System.

📦 Загрузки

Описание: менеджер загрузок: файлы, которые качает панель (в т.ч. результаты торрент-клиента — /srv/downloads/).

Как пользоваться: откройте — список и прогресс; подробнее управление раздачами — приложение Торрент.

📶 Bluetooth

Описание: работа с Bluetooth-адаптером панели: поиск устройств, подключение/отключение пар.

Как пользоваться: включите адаптер → «Сканировать» → выберите устройство → подключить; отключение — из списка пар.

📺 DLNA

Описание: браузер DLNA/UPnP-серверов в сети: просмотр и воспроизведение общих папок с мультимедиа.

Как пользоваться: откройте — панель найдёт серверы (например, MiniDLNA) → переходите по папкам → клик по файлу открывает просмотр.

📡 UPnP

Описание: UPnP Control Point: обнаружение устройств (ТВ, ресиверы) и отправка команд (play/pause) по DLNA/UPnP.

Как пользоваться: запустите поиск → выберите устройство → управляйте воспроизведением.

✈️ ADS-B

Описание: карта бортов: данные ADS-B (dump1090) — какие самолёты над головой, маршрут, высота (нужен ADS-B приёмник и запущенный dump1090).

Как пользоваться: откройте приложение — карта и список бортов; без приёмника окно будет пустым.

🔌 Справочник: API (JSON)

Полный и поддерживаемый каталог эндпоинтов — документация docs/API.md в репозитории 2.0 (та же копия — в публичном Lan-discovery-docs). Ручная копия каталога в справке не ведётся: она расходится с кодом.

Опорные эндпоинты: GET /api/status — общий статус; GET /api/dashboard — агрегат для шапки (система/здоровье/устройства/события); GET /api/health — версия/аптайм/бэкапы. Авторизация — сессионная cookie, mutation-запросы требуют CSRF-токен (заголовок X-CSRFToken).

Резервные копии

Бэкапы хранятся рядом с исходными файлами и в /srv/backup-db (системный раздел {{ hf.root_kind_label }}). Рекомендации:

  • Перед любым изменением app.py — бэкап: cp /opt/lan-discovery/app.py /opt/lan-discovery/app.py.backup-$(date +%Y%m%d-%H%M%S)

  • Восстановление — из файлов .backup-* или через страницу «Система»
🚨 Справочник: решение проблем

Панель не открывается

  • Проверьте статус: systemctl status lan-discovery
  • Посмотрите логи: journalctl -u lan-discovery -n 50
  • Проверьте порт: ss -tlnp | grep {{ hf.web_port }}
  • Перезапустите: systemctl restart lan-discovery
  • Если не помогло — аварийный доступ: {{ hf.restore_url }}

Устройства не обнаруживаются

  • Убедитесь что устройства в одной подсети ({{ hf.subnet }})
  • Проверьте nmap: nmap -sn -PR {{ hf.subnet }}
  • Убедитесь что ARP-сканирование не блокируется файрволом

Погода не обновляется

  • Кэш погоды — 15–30 минут, обновляется при обращении к странице/шапке
  • Проверьте доступность API: curl "https://api.open-meteo.com/v1/forecast?latitude={{ hf.lat|round(1) }}&longitude={{ hf.lon|round(1) }}¤t_weather=true"
  • Посмотрите логи панели: journalctl -u lan-discovery -n 50

Бэкап БД не создаётся

  • Вручную: cp /opt/lan-discovery/devices.db /opt/lan-discovery/devices.db.backup-$(date +%Y%m%d-%H%M%S)
  • Проверьте место: df -h /
  • Бэкап со страницы «Система» пишет в /srv/backup-db

Ошибка синтаксиса Python

  • Проверка: python3 -c "import py_compile; py_compile.compile('/opt/lan-discovery/app.py', doraise=True)"
  • Восстановление из бэкапа: cp /opt/lan-discovery/app.py.backup-XXXXXX /opt/lan-discovery/app.py

Клонирование не запускается

  • Клонирование eMMC → SD отключено, пока система загружена с SD-карты — dd перезаписал бы работающую систему (на этой панели система: {{ hf.root_src }}, {{ hf.root_kind_label }})
  • Если система загружена с eMMC: нажмите «Проверить SD» и убедитесь, что разделы SD не смонтированы: {% if hf.sd_dev %}umount /dev/{{ hf.sd_dev }}*{% else %}SD-карта не обнаружена{% endif %}
    • {% if hf.emmc_dev %}
  • eMMC = /dev/{{ hf.emmc_dev }}
    • {% endif %}

Тема/фон панели не применяется

  • Выбор хранится в браузере (localStorage) — проверьте на том же устройстве/браузере
  • Обновите страницу (Ctrl+F5): старый style.css мог быть в кэше
  • Глобальный дефолт задаётся блоком «Внешний вид» (System → Внешний вид)
❓ Справочник: FAQ

Как добавить IPTV-плейлист?

Вкладка System → блок «IPTV» → введите URL m3u-файла → «Добавить».

Как добавить веб-камеру?

Приложения → 📷 Камеры → «Добавить» → URL потока (RTSP/HTTP) → сохранить.

Как добавить онлайн-радио?

Приложения → 📻 Радио → «Добавить» → URL потока и название станции.

Как работает генератор паролей?

Приложения → 🔐 Пароли → настройте длину и типы символов → «Сгенерировать».

Как сделать полный backup системы?

Файловые бэкапы — вручную (раздел «Администрирование»), БД — через System → «Backup БД». Образ SD — утилитой dd на другой диск.

Как восстановить систему из backup?

Файлы — из .backup-* рядом с оригиналами; БД — System → «Восстановить БД»; аварийный доступ — restore-server.service (порт 8081).

Как подключиться по SSH?

ssh root@{{ hf.primary_ip }} (пароль — от root; не храните его в открытом виде). Рекомендуется настроить SSH-ключи.

Как перезагрузить/выключить сервер из панели?

System → «Управление питанием» → «Перезагрузить» / «Выключить» — с подтверждением.

Где хранятся данные torrent-клиента?

/srv/downloads/; конфигурация Transmission — в /etc/transmission-daemon/.

Как обновить панель?

Измените код, затем systemctl restart lan-discovery. Перед изменением обязательно сделайте бэкап!

Как включить/выключить раздел?

Admin → Модули → переключатель модуля; выключенный модуль исчезает из меню и гасит свои страницы.

Как сменить вид панели (тема/фон/акцент)?

System → блок «Внешний вид»: тема (авто/тёмная/светлая), фон, акцент — применяется сразу; админ может сделать выбор стартовым для всех («По умолчанию для всех»).
